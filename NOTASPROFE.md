# Uso de inteligencia artificial en el proyecto

Utilizamos inteligencia artificial como apoyo para el desarrollo de MarketSoft Frontend, correspondiente a la Actividad Colaborativa II de Programación IV. Este proyecto continúa el trabajo de [la API de la actividad anterior](https://github.com/Delarbol/actividad_1_progIV), agregando una interfaz desde la cual se pueden administrar los datos del supermercado.

## Explicación de la solicitud inicial

El prompt fue:

Desarrolla este proyecto como complemento al proyecto de la API anterior de acuerdo con las instrucciones contenidas en el archivo adjunto.


## Revisión del proyecto

Posteriormente procedimos a hacer una revisión y validación. En el README dejamos documentada la verificación local de la interfaz, su conexión con el backend y la compilación de producción. También agregamos comentarios en las partes más importantes del código para explicar cómo se cargan los datos, cómo se reutilizan los formularios y cómo se administran las ventas.
